# Maths Arcade teaching resources

Atlas Open Mathematics · Albert Tan Sin Hon, project director · 28 November 2026

Choose the player sheets for independent or paired play. The teaching guide contains worked solutions, counterexamples, assessments and research investigations for the six games. Each shared opening has a fixed level and seed so the position can be reconstructed. [Teaching resources on Albert’s website](https://alberttansinhon.com/math-arcade/teaching/)

| Six player sheets | [Twelve positions, questions and board descriptions](PLAYER_SHEETS.md) | [Download the six player sheets (PDF)](https://raw.githubusercontent.com/Albertito-AI/atlas-open-mathematics/main/docs/teaching/Maths_Arcade_Player_Sheets.pdf) |

The guide contains 20 replayable positions across the six games. Each player sheet includes an opening and a transfer exercise. The classroom designs have yet to be evaluated with learners. [Play the games](https://alberttansinhon.com/math-arcade/) · [Read the underlying research](https://albertito-ai.github.io/Albertito-AI/maths-arcade-research/) · [Check the calculations](../../research/arcade/README.md) · [Visit the club pilot](https://alberttansinhon.com/math-arcade/club-pilot/)
